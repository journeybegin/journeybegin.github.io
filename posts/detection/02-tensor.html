tensor可以叫做张量，线性代数通常叫做向量和矩阵，而向量就是一维张量、矩阵是二维张量，只不过张量还可以是三维的、四维的，只是维数高了之后，我们难以理解，因此统一把它都叫做张量。在torch中，张量是一个数据类型，也就是tensor。

张量

具有一个轴的张量即向量（vector），具有两个轴的张量即矩阵（matrix），GPU很好地支持加速张量计算，且张量类支持自动微分。
下面是如何使用torch的函数创建张量和操作张量的代码（其实跟MATLAB很像）。

张量的创建

import torch

vector = torch.arange(12) # 类似range()对象，arange([start,] stop [,step])
zero_matrix = torch.zeros(2, 3, 4) # 2是最高维度,但序号为0,创建全0矩阵
one_matrix = torch.ones(2, 3, 4) # 创建全1矩阵
randn_matrix = torch.randn(2, 4) # 创建一个元素符合均值0，方差1的标准正态分布的二维张量
custom_matrix = torch.tensor([[4, 3, 2, 1], [8, 7, 6, 5]]) # 手动创建张量
print(vector)
print(one_matrix)

除上述外还有常用创建函数：

  • normal():生成正态分布，均值与标准差参数要么是浮点数要么是张量，还可以指定形状如torch.normal(0.0,1.0,(3,4))
  • linspace()：只知道start与end时用linspace构造等差数列，与arange的区别：包含end，最后参数是生成多少个等距的数

张量的基础操作：形状、拼接与类型转换

  1. 改变形状
matrix = torch.arange(24).reshape(2, 3, 4) # 重组成3行4列的二维张量
print(torch.numel(matrix)) # 统计元素个数
print(matrix.shape) # 返回张量各个轴的维度
print(matrix.reshape(2, 4, -1)) # 可以用-1自动计算另一维度
print(matrix.stride()) # 返回的元组参数从左到右:高维到低维,元素内存地址相隔的步长

matrix2 = vector.view(2, -1) # view()也用于改变形状
matrix2 = matrix2.unsqueeze(1) # 在第2维增加“1”，形状变为2*1*6
print(matrix2.transpose(0, 1)) # 根据序号互换维度,形状变为1*2*6

修改张量形状的函数之间的差别：

  • reshape(a,b)先检验张量元素储存是否连续，不连续（比如将原张量转置后）则不共享返回一个新张量，可以认为将张量展平为序列重新划分，元素顺序不会发生变化
  • view(a,b)的特点是与原张量共享一个内存,原张量不连续会报错
  • resize_(a,b)直接修改原张量，总数量不足自动补足
  • squeeze(n)与unsqueeze(n)在第n维压缩和增加维度，squeeze()的操作与MATLAB的同名函数一样
  • transpose()互换两个维度，permute()交换维度更多样。permute()/transpose()与reshape()/view()不同，交换维度改变了元素读取顺序（存储顺序不变），换一套轴的读法：输出每一维来自输入的哪一维。例如matrix2.permute(2, 0, 1)是将原来的第1维的元素作为第0的元素了

row_combine = torch.cat((custom_matrix, randn_matrix), dim=0) # 按第0维组合

print(row_combine, column_combine, sep='\n')

torch.cat((tensor_a, tensor_b), dim=n)可以认为是将第n维为轴，叠放两个张量，所以第n维会展宽
torch.stack([tensor_a, tensor_b], dim=n)可以看做是torch.cat([tensor.unsqueeze(n) for tensor in list], dim=n)先在第n维插入一个大小为1的维度，再沿这个维度用cat合并。还可以用切片理解stack()，上面的代码中row_combine[0,:,:] 等于 custom_matrix，column_combine[:,:,1] 等于 randn_matrix

import torch.nn.functional as F

对于任意具有相同形状的张量，常见的标准算术运算符（+、-、*、/和**）都可以被重载为按元素运算。另外还有许多逐元素运算函数：torch.sqrt()、torch.abs()、torch.ceil()、torch.exp()等等
torch.std()、torch.mean()、torch.max()等统计函数生成一个标量

  1. 向量内积与矩阵乘法
x = torch.tensor([1., 2., 4., 8.])   # float32

print(torch.matmul((matrix - one_matrix), x)) # matrix是整形直接与x相乘将报错，(matrix - one_matrix)可以自动转化为浮点型 
(matrix - one_matrix) @ x
tensor([[ 19.,  79., 139.],
        [199., 259., 319.]])
tensor([[ 19.,  79., 139.],
        [199., 259., 319.]])

torch.matmul()/@是通用矩阵乘法函数，根据输入的两个张量的维度自动选择torch.dot()（内积，必须两个一维向量）、torch.mm()（二维矩阵乘法）、torch.bmm()（三维矩阵乘法）。注意两个张量的元素类型dtype必须一致。
另有torch.trace()（矩阵的迹）、torch.inverse()（求逆矩阵）、torch.svd()奇异值分解等矩阵方法

  1. 广播机制
z = torch.tensor([[1], [3], [5]])
print(x+z)
tensor([[ 2.,  3.,  5.,  9.],
        [ 4.,  5.,  7., 11.],
        [ 6.,  7.,  9., 13.]])

两个张量要么某维度相等，要么两个张量都有一个维度为1，从最右边维度对齐，复制扩展原元素。x.shape为(1, 4)，则广播后先有z.shape=(3, 4),z(0, :)=[1, 1, 1, 1],z(1, :)=[3, 3, 3, 3]，然后x.shape=(3, 4),x(1, :)=[1., 2., 4., 8.]，最终逐元素相加。
torch.matmul()/@运算的两个张量可以最后两维满足矩阵乘法规则，其余维度不同按广播规则处理。

  1. 自动微分
var = torch.arange(4.0, requires_grad=True) # variable封装可以弃用了，现在添加requires_grad更方便
func = 2*torch.matmul(var, var)
func.backward() #对输出使用backward
print(var.grad) # 2x^2求导4x
tensor([ 0.,  4.,  8., 12.])
